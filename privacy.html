Privacy

Last updated October 26, 2026

GitHub Flow Analytics supports Google sign-in for public analysis and GitHub authorization for repositories your GitHub identity can access.

Information saved

When you sign in, we save your verified Google email address, Google's stable account identifier, the first and most recent sign-in times, and a sign-in count. We use this information to recognize returning users and understand account usage. We do not use it for marketing, sell it, or send it to the AI coach.

Repository and AI requests

Private analysis requires a caller-authorized GitHub credential and explicit consent. The service reads through that identity, never through the deployment token. Private repository metadata, selected documents, README, releases and issue text can be sent to Gemini for context research. That context and bounded PR descriptions or issue titles/descriptions are sent to TypeSafe's Jev for intent scoring. Optional owner-supplied strategic context is also processed by these services. GitHub credentials are never sent to AI providers. If you ask the AI coach a question, the question and repository metrics are sent to Gemini.

For value-intent and cost-of-delay analysis, public repository metadata, README, a bounded document-path catalog, selected repository documents, recent release notes and sampled open issue text are sent to Google’s Gemini service to research product context and strategic direction. The researched context and the first 1,500 characters of each description for up to 30 public pull requests are sent to TypeSafe’s Jev service to assess intended value, time criticality, opportunity runway and product-risk reduction. These are intent estimates, not measured outcomes or implementation-risk assessments. Google sign-in details are not sent to either service. Optional caller-supplied API keys are used only for the current request; they are not saved in browser storage, analysis results or the shared analysis cache.

Storage and deletion

GitHub authorization stores your GitHub identifier, login and access token server-side in Cloudflare D1. Sessions authorize access for up to eight hours, or the provider's shorter expiry; expired records are deleted by the next successful hourly production cleanup. The browser receives only an opaque, HTTP-only session cookie. API bearer credentials are verified per request and are not stored as sign-in sessions. OAuth state is valid for ten minutes; expired state and PKCE verifiers are also removed by this cleanup. Sign out removes the current session; Delete account removes all saved GitHub sessions for that identity. This does not revoke an independently supplied GitHub token or the GitHub app grant.

Private PR results may be cached for up to six hours under the GitHub user's identity and a random analysis identifier; chat rechecks repository access. They never enter the public cache. Issue-value requests and owner context are not cached by this service. Local study scripts write private request/results only to the directory you select. Deleting sign-in sessions does not immediately erase cached analysis; cached results expire at their stated TTL. Authenticated API responses use Cache-Control: no-store.

Account records and short-lived sign-in sessions are stored in Cloudflare's database. Choose Delete account in the app to remove your account record and sign-in sessions. A session cookie stays in your browser for up to fourteen days and is protected from JavaScript access.
